# Qur'an Quest "Sample questions" demo

**STATUS: NEEDS REVIEW before merge.** A teacher or scholar must verify every question, answer and citation below, and the Arabic text in particular, before this goes to production.

Where: the `#quest` section of `index.html`, `ar.html`, `fr.html`, `ms.html` (plain inline JS, no network, no storage). It is labelled "Sample questions" and says it is a short sample, not the game itself. It does not show maze mechanics. The "Play the full game" link and the section button go to `/quran-games`.

Citation format shown to the reader: `Citation: <Surah name>, <surah>:<verse>`.

| # | Question (English) | Options (correct in bold) | Citation |
|---|---|---|---|
| 1 | According to Surah Al-Ikhlas, Allah is… | Two / **One** / Three | Al-Ikhlas, 112:1 |
| 2 | Surah Ash-Sharh says that with hardship comes… | Wealth / Fear / **Ease** | Ash-Sharh, 94:6 (the same statement is also in 94:5) |
| 3 | In which surah is Ayat al-Kursi, the Throne Verse? | Al-Fatihah / **Al-Baqarah** / Al-Ikhlas | Al-Baqarah, 2:255 |

## Translations (all marked for review)

### Français
1. Selon la sourate Al-Ikhlas, Allah est… — Deux / **Un** / Trois — Al-Ikhlas, 112:1
2. La sourate Ash-Sharh dit qu'avec la difficulté vient… — La richesse / La peur / **La facilité** — Ash-Sharh, 94:6
3. Dans quelle sourate se trouve Ayat al-Kursi, le Verset du Trône ? — Al-Fatihah / **Al-Baqarah** / Al-Ikhlas — Al-Baqarah, 2:255

### Bahasa Melayu
1. Menurut surah Al-Ikhlas, Allah ialah… — Dua / **Esa** / Tiga — Al-Ikhlas, 112:1
2. Surah Asy-Syarh menyatakan bahawa bersama kesulitan ada… — Kekayaan / Ketakutan / **Kemudahan** — Asy-Syarh, 94:6
3. Ayat al-Kursi terdapat dalam surah yang mana? — Al-Fatihah / **Al-Baqarah** / Al-Ikhlas — Al-Baqarah, 2:255
